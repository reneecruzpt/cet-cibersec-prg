Coleção de scripts, exercícios práticos e módulos desenvolvidos no âmbito do **Curso de Especialização Tecnológica (CET) em Cibersegurança**, abrangendo programação estruturada em **C**, automação em **Python** e técnicas de **análise e triagem de evidências digitais**.

---

## 📂 Estrutura Curricular dos Módulos

```text
├── 9191 - Intro às técnicas de análise de evidências/
│   ├── Aula_02/          # Programação estruturada vs. funcional na manipulação de dados
│   ├── Aula_03/          # Validação de cadeias de caracteres, palíndromos e integridade
│   ├── Aula_04/          # Manipulação e extração de listas de dados
│   └── Aula_05/          # Automação de varredura de diretórios e inspeção de ficheiros
├── algoritmos_em_c/      # Algoritmos fundamentais, controlo de fluxo e arrays em linguagem C
├── Calculators/          # Evolução incremental de calculadoras modulares em Python (v1 a v3)
├── Manipulação_de_Diretórios/ # Técnicas de inspeção do sistema de ficheiros com o módulo os
├── Tarefa_Python/        # Scripts de automação de tarefas de recolha e filtragem
├── Python/               # Fundamentos da linguagem: tipos, loops, funções, time e POO
└── Reference solution M6L2/ # Soluções de lógica de colisões e mecânicas 2D
```

---

## 🎯 Principais Competências Desenvolvidas

- **Análise e Forense Digital:**
  - Extração sistemática de metadados e atributos do sistema de ficheiros.
  - Varredura recursiva de diretórios para catalogação de artefactos.
  - Processamento e normalização de dados brutos de texto e logs.
- **Programação em C:**
  - Gestão de memória, tipos primitivos, estruturas condicionais e ciclos iterativos.
- **Automação com Python:**
  - Scripts utilitários de triagem rápida com bibliotecas da Standard Library (`os`, `sys`, `time`, `random`).
  - Lógica orientada a objetos (POO) e modularização de código.
